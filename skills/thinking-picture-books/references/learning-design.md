# 教学设计：从找得到到想得明白

## 一个可观察目标

不用“提升思维力”代替目标。写成“孩子能按形状给物品分组，并在换成颜色规则后重新分组”“能指出支持选择的两条可见线索”。一次表现不能证明稳定掌握；同规则换场景再观察。

每页的最小闭环：**故事需要 → 明确问题 → 可见证据 → 孩子操作 → 解释/检验 → 故事结果**。有些跨页可承载一个闭环，别每页塞多个新规则。孩子可以指、说、摆、画；训练推理时不附加不必要的识字或绘画门槛。

## 能力与题型库

| 能力 | 基础机制 | 提升与迁移 | 必查问题 |
|---|---|---|---|
| 视觉辨别 | 样本与目标匹配，形状嵌入场景 | 换大小/朝向后认不变特征；说依据 | 没有隐含颜色捷径；轮廓完整可认 |
| 选择性注意 | 按特征从干扰项中找目标 | 目标特征相近、按计划扫描 | 密度不是唯一难度；目标不微小模糊 |
| 分类与概括 | 按一个明确属性分组 | 双属性交集、重分类、自己提规则 | 类别规则明确；开放分类允许不同理由 |
| 比较与排序 | 长短、数量等单维比较 | 多项排序、插入中间项 | 长度用同一基线/尺度，数量不受面积误导 |
| 规律与预测 | 重复单元 AB、AAB 的延续 | 找错、补缺、换材料保留结构、自己造规律 | 至少展示足够重复；限定采用的规则族 |
| 空间与关系 | 上下里外、拼合、旋转 | 地图路线、视角转换、分解组合 | 明确参考系；遮挡不制造假边界 |
| 数感与对应 | 一物一数、一一分配、多少比较 | 数字符号对应数量、分合、补缺 | 数字轮廓识别不等于数量理解；限定计数集合 |
| 工作记忆 | 观察后翻页记住物件或顺序 | 短延迟、改变位置、更新一个项目 | 必须有隐藏/翻页，目标一直可见不叫记忆题 |
| 抑制控制 | 看到指定信号才行动 | 只指符合规则者、忽略显眼干扰 | 不用紧张计时；说明动作规则 |
| 认知灵活性 | 同一组物件换分类规则 | 显示切换信号、讨论另一种分法 | 换规则可见，不能暗换答案标准 |
| 因果与证据推理 | 根据可见痕迹或先后关系解释 | 两线索排除、反例、信息不足 | 食物出现在肚子图案里只是视觉匹配，不能当现实证明 |
| 计划与问题解决 | 为明确目标选步骤/路线 | 有限制的方案比较、执行后调整 | 路径真实连通；“最短”须可度量；允许多条同优解 |
| 类比与关系迁移 | 从“相同关系”找另一对 | 改表面物件，保留部分-整体或功能关系 | 不只比较长得像；关系描述可检验 |
| 发散与元认知 | 给出多个方案、说明如何发现 | 自编一道题，检验他人解法 | 不设伪唯一答案；评价理由和约束满足 |

这些是可设计的练习维度，不是互相独立的心理测验。一本集中练一个主能力，辅助能力服务它，不堆砌全部类别。

## 年龄起点与难度向量

下表是本 Skill 的编辑启发式，**不是发展里程碑、常模或诊断阈值**。先用易题观察，再调整。

| 读者起点 | 可尝试的配置 | 语言与参与 |
|---|---|---|
| 2–3岁 | 熟悉物件，单一特征，2–3个明显不同候选；配对/指认/装入 | 成人短句示范，允许模仿，不要求解释抽象规则 |
| 3–4岁 | 单条件分类，3–4个候选，直观比较、简单AB | 一次一动作，可指认代替说出名称 |
| 4–6岁 | 4–6个候选，简单规律/空间，熟悉后尝试双线索 | 短问题，可追问“你看到了什么” |
| 6–8岁 | 多步计划、规则切换、2–3条显式线索 | 可比较解法，保留图示支持 |
| 8岁以上 | 更长关系链、反例、开放设计 | 主题尊重年龄；复杂度按实际能力选择 |

难度记录为向量：`目标数、候选数、干扰相似度、属性维度、推理步数、记忆负荷、线索显著度、成人支持、语言负荷、反应方式`。一次通常只加一个主要认知负荷，不同时加密画面、加长文字、增加条件。

- 入门：减少干扰，提供清楚示例和图示，保留主技能。
- 标准：减少提示，加入一个变化，题面仍充分可见。
- 挑战：增加规则深度、反例或迁移；不靠缩小字号、隐藏目标、恐惧或倒计时。

## 故事结构与反馈

故事有具体愿望，如为朋友准备野餐、修好邮局、安排返航。每题解决一个真实障碍；无关关卡应删掉。画面有情感节奏和翻页悬念，留出轻松页，不把练习册题目机械放进背景里。

分层提示放成人指南：第一层提醒看哪里；第二层提示采用什么策略；第三层共同演示一个步骤。答错时问“我们再找一条线索”，反馈具体策略（逐个比较、排除不符条件者），不用聪明/笨评价。

轻量观察记录只记：独立完成 / 经提示完成 / 仍需共同操作；同时记孩子的理由。连续明显费力就减少负荷，轻松完成再加一个变化。任何次数与比例都是教学选择，不转为能力分数。

迁移分层：同图换位置→同规则换材料/场景→生活中找例子→孩子自己出题。绘本提供练习机会，不能仅凭成品推断长期效果。

## 无障碍与可读性

关键区用清楚轮廓、充足间隔、稳定阅读顺序。低龄主指令宜一短句、每页一个动作；字数是编辑预算，不是发展定律。颜色不应成为非颜色题的唯一线索；需要区分颜色时可用纹理/符号作辅助并注明。不要用复杂字体、装饰字、拼音堆叠牺牲辨识。计数目标与背景装饰分区，装订中缝和裁切区不放关键线索。
