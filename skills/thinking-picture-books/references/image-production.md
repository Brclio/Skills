# imagegen 图文一体制作

先读当前 imagegen Skill；工具签名以当前环境为准。本文件只补充绘本特有要求。

## 参考图与调用

- 本地参考先 `view_image`；所有目标都有路径时按当前内置工具的 `referenced_image_paths` 传入。
- 至少一张必要目标只有会话图片时，用 `num_last_images_to_include`，取能覆盖所有目标的最小数量（当前上限5）。两种方式不同时使用；无法包含全部目标时请用户重新附缺少的图。
- 全新、无参考生成不传引用参数。角色照片用于身份参考，不是让模型复制照片背景；明确每张输入的角色。
- 每本先保存通过核查的角色设定，再逐页调用。批量为每个资产独立调用，维持清晰的页码→提示词→输出路径映射。
- 输出路径采用工具真实返回结果。默认输出在 `$CODEX_HOME` 下，项目成品复制到工作区；不臆造工具的目标路径参数。展示结果使用工具原生图片或真实本地路径。

## 完整页提示词骨架

```text
Use case: illustration-story
Asset type: 一本面向{年龄}的原创思维训练绘本的第{页码}页，完整图文成品
Primary request: {故事动作}；孩子通过{主要操作}推进{剧情目标}
Input images: Image 1=已验证角色身份参考；Image 2=已验证画风/场景参考（如有）
Scene/backdrop: {地点、视角、任务区、低干扰背景}
Subject: {主角视觉DNA的3至6个锚点、姿态；避免暗示答案的眼神与手势}
Style/medium: {全书统一画风、线条和材质}
Composition/framing: {统一比例、阅读顺序、文字区、题目区、必要留白与安全边距}
Task objects: {逐个对象、位置、形状、数量、相互关系、干扰项；只描述可见事实}
Text (verbatim): "{逐字准确的标题/对白/指令/页码}"
Typography: 简洁清楚的中文印刷体，适合目标儿童；文字必须由本次imagegen连同整页生成，逐字无误，不额外加字
Constraints: {角色不变项、题目不变项、无额外可计数目标、关键特征无遮挡}
Avoid: 同页答案提示、装饰性伪文字、错误手指、重复物件、题目区无关符号
```

逻辑密集的纯题面可用 `scientific-educational`；整本叙事页默认 `illustration-story`。不要在普通正文图提示中粘贴“正确答案是K3”或整份成人解答，以免泄露。可以完整描述对象规格和各自属性，确保可解。

## 文字与版式

文字先校对再进入生成提示。低龄主要问题一般控制在一句可朗读短句；复杂解释放成人指南，不把长文挤进角落。一页一个视觉焦点，任务区干净，角色和环境能服务故事。问题、对白、页码都是图像的一部分，不能后贴。

需要拼音、双语或长答案时，应拆页或降低信息密度；用户页数固定则缩短措辞，不静默增页。不用脚本把书内文字变成图片再贴回整页。检查工具可裁切放大供阅读，但不能用检查裁片替换正式图像。

## 修复

保存错误版本，使用 imagegen 编辑。一次针对一个明确问题，重申不变项，例如：

```text
Use case: text-localization
Asset type: 绘本第4页完整成品修订
Primary request: 仅把页上错字修正为下列完整句子
Text (verbatim): "找到有圆孔、带两颗星星的钥匙。"
Constraints: 保持四把钥匙的位置、孔形、星数、角色身份、背景与页幅不变；不增加其他文字
```

数量/形状错误用 `precise-object-edit`，身份漂移用 `identity-preserve`；修后再次完整解题与逐字检查。不能因为只改文字就假设对象没变。

## 输出边界

角色图、封面、所有正文图、成人指南/答案的书内页都必须来自 imagegen。Markdown 文稿/QA 属于制作记录，可用文本工具。Python 等可以清点文件、读取尺寸、OCR、检查、按原图拼成 PDF；不得新增视觉成分、补画正确答案、给页面加页码或修字。PDF 印刷适用性需要看实际分辨率和版心，不能仅把低分辨率图贴进高 DPI 容器就称为高清印刷版。
