# 逐页规格、可解性与核查

## 每页规格

计划文件可以是 JSON 或结构化 Markdown，至少含：

```yaml
page_id: P04
paired_page_id: null # 样本/提问分离时填配对页号，并注明目标是否可见
role: task # cover / story / demonstration / task / transfer / creative / adult-guide / answers
story_beat: 角色需要找到通往温室的钥匙
primary_skill: 双条件筛选
child_action: 指出符合两条线索的钥匙
exact_text: ["找到有圆孔、带两颗星星的钥匙。"]
rule: 同时满足圆孔与恰好两颗星星
entities:
  - {id: K1, hole: circle, stars: 1}
  - {id: K2, hole: square, stars: 2}
  - {id: K3, hole: circle, stars: 2}
  - {id: K4, hole: square, stars: 1}
layout: 四把相同大小钥匙分开摆在浅色桌面，孔和星星无遮挡；无其他钥匙或星形装饰
answer_type: unique # unique / multiple / open
accepted_answers: [K3]
proof: K1星数不符，K2孔形不符，K4两项都不符；只有K3同时满足
hints: [先看看钥匙上的孔, 只在圆孔钥匙里数星星, 一起比较K1和K3的星星数]
transfer: 改成选择同时有条纹和圆盖的水壶
continuity: 主角仍穿固定外套，找到的钥匙下一页开启温室
visual_invariants: [四把钥匙, 每个孔形与星数准确, 无指向正确答案的目光或高亮]
```

上例中的 id 为内部标识，不自动印入儿童页。若题目需要编号，编号须写入 exact_text 并由 imagegen 准确生成。答案/理由默认不印在同页，成人答案可用“从左数第三把”等明确位置描述。

## 逻辑校验

- **分类/排除**：列出候选×属性表，对规则计算每个候选；唯一题必须恰好一个。开放题不要偷设唯一标准。
- **数数**：列出计数范围、实际对象清单、是否排除装饰/遮挡/图标。图像重新清点，不能仅相信生成提示中的数字。
- **序列**：声明重复单元、已展示项、空位与允许规则。有限序列通常能编出多种延续；不能宣称数学绝对唯一。低龄题可写“照着这组重复”，显示至少两个完整单元，再问下一项。
- **找不同**：先列确定的差异清单；最终两图之间的一切非目标差异也可能构成答案，严格题需要逐区比对。不能把生成噪声忽略为“不是想考的”。
- **迷宫/路线**：先建立节点与可通行边，再验证连通和条件，图像须保留拓扑。若要求最短，定义步数/格数，检查并列最短；图像无法稳定呈现时用少量明显路口的路线选择，不伪称精密迷宫。
- **记忆**：观察页与提问页分开，提问页不露答案；规定孩子可做什么和翻页方式。延迟与项目数按能力调节，不假定一次答错就是记忆差。
- **因果**：区分看到的事实、可能解释、还缺什么证据。不能凭可爱角色外貌、喜欢某食物等常识唯一指认“谁做的”。
- **几何**：若只问轮廓不要求尺寸，允许旋转与大小变化；涉及长度、面积则保持比例与基线。正方形属于矩形，不把课堂口语分类写成错误的几何事实。

## 两次验证，分别留证

1. 出图前：解题规格通过，只证明设计可解。
2. 出图后：不看答案，按实际图像作答。写出视觉证据，再与规格核对。若图画偏离规格，修图或重新设计并同步答案，不能悄悄容忍。

有独立代理时，给最终图、儿童题目与年龄，不给预设答案，要求说明所见和不确定处。若代理直接复述规格，无独立解题价值。无代理则隔开答案自行复核并如实记录方式。

## QA 记录

每页记录：文件与版本、逐字文字核对、题面数量/关系、独立答案、DNA/道具、可读性、状态、修复记录、复核时间。可用表格，不需要虚构分数。

阻断项：错/漏关键文字；无解或伪唯一；目标误增误减；相同钥匙重复；关键部位遮挡；答案提前泄漏；人物锚点改变；任务需要的细节无法辨认。

非阻断美术项：不影响任务的微小纹理、次要背景变化等。以儿童理解和作品质量判断，不为无关像素无限迭代。

所有任务页通过后才能称“已完成内容核查”。PDF 仅装订成功不证明文字和逻辑通过；内置生成成功也不证明具有教学效果。
