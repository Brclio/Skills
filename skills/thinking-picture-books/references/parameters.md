# 参数与默认策略

接受自然语言，不强迫填写表单。以下均可选；用户给出的字段优先于默认和随机。未指定绝不等于忽略历史已确认设定。

| 字段 | 内容 | 缺省处理 |
|---|---|---|
| characters / 角色 | 名字、描述、一个或多个角色对象 | 原创动物主角 1 位，必要时配角 0–2 位 |
| character_refs / 角色参考 | 本地路径或会话图片；可按角色分组 | 有参考即提取 DNA，不另随机主角 |
| scene / 场景 | 地点与环境 | 结合主题选择可理解且有行动机会的场景 |
| theme / 主题 | 内容世界、兴趣或情感主题 | 从日常、自然、交通、探险、合作等选择 |
| learning_focus / 训练重点 | 观察、分类、规律、空间、数感、推理等 | 一个主要能力，最多两个辅助能力 |
| age / 年龄 | 数字或年龄区间，支持自然语言 | 4–6 岁亲子共读，记录是假设；不随机真实年龄 |
| difficulty / 难度 | 入门、标准、挑战或具体要求 | 标准，按年龄与已知能力调整 |
| abilities / 已有能力 | 识字、数数、语言、动作、偏好和支持需要 | 成人读题、孩子指认/讲述，不要求识字或精细书写 |
| style / 风格 | 水彩、拼贴、蜡笔等 | 清楚轮廓、柔和色块、有纸感但题目区域纹理克制 |
| language / 语言 | 简体中文、双语等 | 简体中文；双语占两份文字预算 |
| page_count / 总页数 | 包括封面、正文、书内成人附录的正式图文页总数，不含角色设定图 | 默认32页；常规最低30页，可指定30、32、36或更多页 |
| book_count / 册数 | 正整数 | 1 |
| format / 版式 | 单页/跨页、横竖比例、印刷尺寸 | 横向单页约3:2、全书一致；实际像素以生成结果为准 |
| output_dir / 输出目录 | 用户指定位置 | 当前工作区 output 下新的书名版本目录 |
| seed / 随机种子 | 整数 | 新随机整数，保存在 brief 中 |
| avoid / 避免内容 | 害怕的元素、颜色限制、排除题型 | 不默认加入恐吓、羞辱或竞争性速度排名 |
| constraints / 其他约束 | 指定题数、物件、系列角色、品牌等 | 原样保存，落实到逐页规格 |

## 页数与分段契约

正式绘本默认32页，最低30页；不能因年龄小、零参数或制作便利自动减到短篇。32页可安排为封面1页、故事与任务24页、迁移和开放创造3页、成人指南2页、答案2页；这是可调整的内容预算，不是必须套用的结构。30页和36页等显式页数保持原值。

每页都要有明确作用：引入情境、示范策略、推进任务、检验迁移、邀请创造、故事收束或成人指导。不要用空白页、重复同图、无实质变化的题目、重复答案页凑到页数。角色设定图、制作说明、提示词、核查拼图、弃用版本都不计入正式书页。

低龄和大龄均可分章节阅读；根据年龄、注意状态与已有能力降低或增加单页负荷，并建议每次读一个短章节。章节之间提供自然停顿与下次继续的线索，不要求一次读完全书，也不因此减少总页数。

用户提供“跨页数”时先明确计数单位、换算并记录，不把一张跨页图冒充两张独立成品图。常规制作以阅读顺序中的正式图文页清单核对总数。

若后续用户**明确要求覆写30页下限**，以当次请求为准，人工编排并在 brief 记录覆写来源与实际页数。常规 `resolve_brief.py` 仍拒绝 `page_count < 30`，不会静默补长或提供自动绕过；仅缺少参数时采用32页。不能把“低龄”“快速做一本”等一般描述解释为覆写授权。

## 随机不是任意组合

先锁定显式信息，再选择相容组合。海洋主题可配潮池、礁石、海底邮局；现实宠物可在想象世界穿衣，但保持指定物种和斑纹。不因随机改变真人身份参考或用户指定衣服。

`scripts/resolve_brief.py` 为常规参数提供可复现的随机初稿：

```bash
python3 <skill-dir>/scripts/resolve_brief.py --seed 42 --out <新路径>/brief.json
python3 <skill-dir>/scripts/resolve_brief.py --input <配置.json> --out <新路径>/brief.json
```

脚本不生成图片；接续完整流程。自然语言特殊要求先规范化为 JSON；无法标准化的内容放 constraints/abilities，不丢弃。JSON中的 age 用岁数数值或 `[下限,上限]`；角色参考建议为路径数组或按角色分组的对象。别把缺失文件当作没有提供照片而随机生成。

多本时建立系列表（主角、场景、主题、主要能力、规则结构、反应方式、难度跨度）。固定用户角色，改变未指定维度。用户只说“同一角色”但未给形象时，先原创并锁定一个角色，写入 characters，再扩展各册；不能只传 book_count 让脚本逐册随机。若有已完成 brief，读其系列表；至少在主要规则结构或迁移任务上有真实变化，不能只换名换皮。脚本只生成初稿，不保证跨项目自动去重；duplicate_configuration=false 仅表示整组配置不同，同机制换场景仍可能重复训练结构，必须人工复核系列表。

## 冲突处理

照片与文字差异：明确文字修改优先，其余保留可见特征。多张参考冲突则选最清晰、与描述吻合的图作基准，说明取舍；若无法辨认哪位是目标人物，再询问。

“2岁+挑战”：保留挑战意图，降低语言/动作负荷，使用同龄范围内变化；不直接给复杂多条件推理。确需高阶内容时给成人演示版本并说明假设。“8岁+入门”用适龄题材、基础规则，不用幼儿化语气。

仅无法推进的身份不明、指定输入缺失、互斥硬要求需澄清；继续不依赖该答案的设计。普通页数、衣着、画风自行确定并记录。

## 调用示例

- “用 $thinking-picture-books 做一本。” → 随机角色/场景/主题，默认4–6岁、标准难度、32页。
- “用这张孩子照片做太空故事，5岁，训练分类。” → 先看照片、生成角色设定，分类推动故事。
- “把我家的猫变成主角，3岁，不识字，只用指一指。” → 保留猫的斑纹，成人读短句，单条件选择。
- “同一角色做5本，分别训练观察、规律、空间、数感、推理。” → 固定 DNA，建立系列矩阵，逐页生成和校验。
