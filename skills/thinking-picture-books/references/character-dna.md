# 从真人、动物到稳定的绘本角色

这里的“DNA”是视觉设计记录，不是生物信息分析。

## 输入与提取

每张输入标注身份参考 / 画风参考 / 场景参考 / 编辑目标。先看图再描述。多角色分别编号 C01、C02，保持图片与角色对应；群像目标不明时不猜身份。

真人记录脸形、发型与发际轮廓、可见肤色、眉眼形状、眼镜、标志性配饰、头身比例。动物记录体型、耳形、口鼻、尾形、毛色、斑纹位置及左右侧、爪/蹄特征。使用“角色自身左侧”而非“画面左侧”锁定不对称标记。

不从照片推断姓名、国籍、族群、健康、能力或人格。年龄以用户提供为准；未提供时仅用保守的可见年龄段描述辅助转绘，目标读者年龄另行默认。看不清的背面、眼睛颜色等标为未知；采用一致的创作补全并注明，不称为观察所得。

## DNA 模板

```yaml
character_id: C01
name: 用户给定或原创名称
source_refs: [图片编号或可访问路径]
observed: # 可见事实
  silhouette: ...
  face_or_muzzle: ...
  hair_fur: ...
  distinctive_marks: ...
unknown: [不可见背面等]
designed: # 创作决定
  illustration_translation: 圆润造型、清楚轮廓、保留辨识特征
  proportions: ...
  costume: ...
  palette: ...
  story_traits: 仅作为虚构设定
invariants: [最重要的3至6个视觉锚点]
allowed_variations: [表情、动作、按剧情声明的换装]
forbidden_drift: [斑纹换侧、耳形改变、无故加减配饰等]
```

不强迫角色套用同一萌化脸。风格统一，身份可区分。仅给文字角色时保留指定约束，补齐必要锚点。

## 生成与一致性

1. 用 imagegen 生成角色设定图：正面、侧面、背面、常用表情；必要时拆图避免拥挤。可见标签也由 imagegen 渲染。
2. 验证关键锚点，尤其左右斑纹、眼镜、尾巴和服装。设定图内部不一致时先修复。
3. 每页携带已验证设定图，重申身份锚点。必要时附已通过核查的前页作风格/场景参考。
4. 用道具连续性表记录获得、使用、放下。题目核心道具不得无故消失或复制。
5. 全书并排复核，画面中小角色也要检查。修复人物后重新核查题面，编辑可能改变周围物件。

照片无需复制到可分享的成品目录。默认交付衍生角色图；用户要求原图随包时再包含。相似度属于视觉评估，不宣称数学级身份一致。
