# 课程完整离线归档

用户要求保存课程时，默认处理整门课并保留原文、完整目录及来源提供的全部资源。用户要求“所有已购”时，先枚举当前已购课程与分页，建立来源清单，再逐课处理；每门课程独立文件夹。目录、URL、加密文件或部分成功均不能算完整交付。

## 入口与适配

- 得到：读取 [dedao-workflow.md](references/dedao-workflow.md)，使用内置脚本。
- 极客时间：读取同级已安装的 `geekbang-course-archive/SKILL.md`；不要套用得到接口或算法。
- 其他站点：先验证目录、正文与媒体适配，不宣称通用支持。
- 用户指定位置优先，否则使用当前工作区。确认同课身份后续存，不覆盖笔记或其他课程。只保存本地，不自动上传、发布或分享。

```text
python3 <skill-dir>/scripts/init_archive.py --url <canonical-course-url> --output <absolute-course-dir> --title <observed-title>
```

需 Python、FFmpeg/FFprobe。初始化不联网、不带历史课程数据；现有课程工具保持原样，配置区分已安装版本与可用版本，不能把重跑初始化当成工具迁移。脚本实际参数以 `--help` 为准。

## 采集与原件

1. 使用当前获准浏览器工具和用户登录会话做正常同源只读请求。不要读取 Cookie 数据库、账户凭据或绕过访问限制。401/403/429、验证或权限失败时保存进度，停止依赖请求；连接超时先做有限连接检查，不无限重试。
2. 从当前来源核对课程身份、唯一章节 ID、原始顺序、分页和已发布数量。保存原始正文字符串及 SHA；逐段、引用作者、强调、代码、图片位置生成 Markdown/HTML，不能用摘要替代。未知非空块必须适配或报缺失；来源只给空交互占位时保留位置并明确内容未提供。
3. 建立**来源推导的资源清单**，包括正文/元数据图片、课程介绍媒体、主/额外音频精确 alias、视频、字幕各版本和明确附件。不能从已下载文件倒推期望。评论头像、推荐广告与整站资源不自动镜像；未知嵌入媒体需适配，不能悄然漏掉。
4. 图片保留原始字节与真实格式，包括 BMP；不能因 MIME 不准转码原件。课程介绍的内嵌图片也要下载并改为本地引用。
5. 主音频不能代替加餐 alias。视频独立音轨仅在来源媒体 ID 对应、当前输入已验证且压缩包数据一致时生成无损派生文件，明确标注来源。字幕既保留原件，也进入下载和本地字幕轨。
6. HLS 先保留原始播放清单、全部分片、适用的标准 identity AES 密钥及本地 URI 映射，再仅从本地输入无损封装；原清单不能被改写版覆盖。不支持的 DRM/动态直播清单明确报阻塞。来源私有令牌与标准 HLS 资源密钥分开管理。
7. 明文原件、密文原件、解密原件、正常 Web 片源各用独立路径与角色。按真实返回的最高画质选默认，同画质优先原件；不猜 URL，不覆盖原件，不堆重复播放器。一讲多视频以来源 ID/index 区分；当前适配遇到不支持的多视频明确失败。
8. 旧 v1 密文按 [dedao-legacy-decryption.md](references/dedao-legacy-decryption.md) 验证格式、来源库和真实前缀后解密。只要求真实密文子集解密，再核对明文与密文来源并集；不能把另一片源称为原件解密。

不同媒体下载可并行，共享 `course.json` 的写入必须串行并使用锁及当前版本检查。临时输出写完验证后再合并，私有输入始终在归档外，权限受限并在使用后清理。

## 核验与交付

构建本地目录、介绍、全文搜索、逐讲阅读、媒体/Markdown 下载与字幕播放。运行依赖全部本地化，JS/CSS 带内容哈希版本。原始资料与来源哈希、媒体证据、浏览器验收分角色保存，避免验收报告触发媒体反复处理。

按 [verification-delivery.md](references/verification-delivery.md) 执行。普通增量核验只复用当前 SHA 匹配的证据；用户要求“全面从头核查”使用 `audit_archive.py --mode fresh`，真正读取并解码所有图片帧和音视频流。同轮中断可显式用相同 run ID 续验，跨轮不能冒充新核验。

`finalize_archive.py --apply` 只标记 `local_verified`。实际浏览器加载的数据、JS/CSS 版本及目录、搜索、切换、图片、媒体播放/拖动、字幕和下载均核验后，独立 delivery gate 才标记完整交付。不能用请求成功、磁盘新文件或合成 UI 证据代替当前页面实测。

最终交付网页入口、课程文件夹、真实资源数量与画质、核验报告及缺失原因。未通过的层级如实报告；不把“本地通过”宣称为“全部交付完成”。目录结构与证据边界见 [archive-contract.md](references/archive-contract.md)。
