# 课程完整离线归档

用户给课程或章节链接并要求保存时，默认处理整门课：保留原文与完整目录，下载真实素材，保留正常片源、加密原件及适用的已验证解密版本，生成 Markdown 和离线网站，核验后交付。不把目录、播放地址、加密原件或部分成功算作完整课程。

## 适配与初始化

- **得到 `dedao.cn`**：先读 [references/dedao-workflow.md](references/dedao-workflow.md)，使用本技能内置适配。章节链接先解析所属课程；名称、ID、数量与顺序来自当前来源。
- **极客时间 `time.geekbang.org`**：若同级已安装 `geekbang-course-archive/SKILL.md`，读取并使用其专门适配；不要把得到接口或加密算法套到该站。
- **其他平台**：先观察可访问目录、正文和实际播放源，验证对应适配后再归档；不声称任意站点都已支持。
- 用户指定位置优先，否则在当前工作区建独立课程文件夹。同课检查身份后续存，不覆盖其他课程或笔记。只在本地保存，不自行发布、上传或分享。

得到课程身份确认后：

```text
python3 <skill-dir>/scripts/init_archive.py --url <canonical-course-url> --output <absolute-course-dir> --title <observed-title>
```

初始化器只复制通用模板与工具，不复制历史课程数据。运行时资料留在课程目录；技能目录不收集课程正文或用户授权材料。确认 `ffmpeg`、`ffprobe` 可用，具体脚本参数以 `--help` 为准。

## 全量采集与资源保存

1. 沿用用户已登录页面，通过当前获准的浏览器工具执行正常同源只读请求。认证材料只在会话内使用；不要读浏览器 Cookie 数据库或把账户凭据写入项目。登录、验证、权限失败时保存进度并说明具体阻塞。
2. 保存完整目录、课程介绍、讲师信息和每讲原始结构化正文。核对每章及全课数量、唯一 ID、顺序和已发布范围。保留原始字符串与哈希，按原语言、段落、引用、强调、代码和图片位置生成 Markdown、HTML；不能以摘要代替原文。
3. 下载正文与元数据图片，按 URL 去重并保留不同变体。修复或明确记录未知内容块、漏图、文字差异。Markdown 可使用合法内嵌 HTML 保真。
4. 主音频与正文额外音频按准确 alias 匹配，不用主音频替代加餐/彩蛋。来源明确无该媒体记为 `not_applicable`；有源但未保存才是缺失。
5. 同时检查文章信息和正常网页播放接口，选择实际返回的最高分辨率，不改 URL 猜测高画质。HLS 保存完整清单和全部分片，保留画面与音轨，无损封装 MP4/M4A；字幕、附件按明确来源保存。外部脚注资料单独记录可访问性，不镜像整个外站。
6. 遇到原始加密 MP4，执行 [references/dedao-legacy-decryption.md](references/dedao-legacy-decryption.md) 的适用性检查、真实前缀测试与批量解密。这是技能的完整组成部分；不能跳过后把加密原件称为可播放视频，也不能套用到未经验证的新格式。

正文/图片、音频、视频可并行，但共享 `course.json` 的合并顺序执行。复跑时校验已有文件哈希后续存。

## 网站、核验与交付

沿用模板生成目录、课程介绍、全文搜索、本地音视频、逐讲切换、Markdown/媒体下载和字号调整。运行时样式、脚本、字体、图片与媒体均本地化，不依赖 CDN 或在线课程接口。

实际解密成功后，在已验证片源中保持最高可用画质；同质量时默认播放器采用解密原件。保留正常网页源和加密原件的独立下载，不堆放重复播放器。原始密文、HLS 分片、来源元数据与核验报告保留，移动时保持目录结构。遇到一讲多视频，以来源 ID 和 video_index 区分文件；旧工具若只支持一讲一个，先适配并核验，不静默覆盖或丢掉第二段。

在课程目录执行：

```text
python3 scripts/build_site.py
python3 scripts/build_course_info.py
python3 scripts/build_resources.py
python3 scripts/audit_archive.py
python3 scripts/finalize_archive.py --apply
python3 scripts/audit_archive.py
```

按当前目录动态验收，不能固定示例课程数量：

- 原文字符串逐字节保留；Markdown/HTML 独立对照；本地资源引用存在且哈希一致。
- 媒体具有预期画面与音轨、正确时长，所有音视频流完整解码通过；HLS 清单和分片完整。
- 解密结果绑定真实输入/输出哈希、官方算法版本来源和原件未改证据；不能用另一片源冒充原密文解密。独立复核全部哈希/流/报告，再对首、中、末媒体完整解码。
- 浏览器实测目录、搜索、切换、图片、音视频播放、下载及拖动。使用支持 HTTP Range 的本地预览；文件协议若被工具限制，记录未实测，不绕过限制。临时服务按环境规则清理。

交付本地网页入口、资源目录、真实保存数量与画质、完整性报告和缺失/外部旧链说明。数据与证据边界见 [references/archive-contract.md](references/archive-contract.md)。
