# 来源、实现与限制

上游 WorkBuddy 版本署名为知行。上游原说明称，其依据用户提供的“视频号下载 Skill 全流程拆解”和可观察的腾讯网页行为编写，并参考过本机第三方 `@user_2b46b0cf/wx-video-download` 包；上游说明记载该第三方包未见明确的可再分发许可证。这里保留来源记录，不对是否获得作者许可作出推断。

当前目录为基于该版本的本地修改版 `1.2.0-local-free`，并非上游已发布的官方版本。本地修改移除了作者服务依赖和邀请码要求，任何使用此本地版本的人均可直接调用单条或批量下载入口；无需联系上游作者。此处的“免费”说明本地工具没有作者侧收费或次数核验，不保证腾讯服务长期可用，也不授予上游代码新的许可证、再分发权或内容使用权。

保留的实现包括 Windows 与 macOS 入口（Codex / WorkBuddy 均可调用）、固定隔离环境、单链接与媒体域名校验、文件大小限制、临时文件保护和错误码。批量流程复用同一个专用浏览器登录，逐条解析，最多 4 路并行下载文件，跳过重复项，并记录逐条结果及本地清单。平台限流时停止继续解析。

解析依赖元宝网页内部接口取得可播放票据，再向视频号预览接口请求视频信息，最后保存腾讯媒体地址返回的 MP4。用户仍须本人扫码登录元宝；本工具不是腾讯官方产品，也不是腾讯提供的稳定公开下载 API。网页接口、登录页面或访问规则变化都可能使流程失败。

2026-10-22，本版本在 macOS 成功完成真实单条下载，并对所得 23,099,407 字节 MP4 通过 FFprobe 检查与 FFmpeg 完整解码：时长 468.811 秒，H.264 1280×720 视频、AAC 双声道音频。另有 7 项离线 CLI 回归通过，腾讯接口与媒体响应由测试模拟。Windows、真实多链接批量及各客户端完整流程尚未实测；一次成功不能证明长期稳定性。实测视频及专用浏览器登录资料不随仓库发布。

适用范围：用户本人发布或明确获授权保存的视频，包括经授权的多条备份。用户仍需遵守著作权、内容授权和平台规则。Skill 不提供无授权批量搬运、私密/付费内容绕过、风控规避、去水印承诺或云端代存。专用浏览器资料目录含登录状态，必须留在用户本机。
